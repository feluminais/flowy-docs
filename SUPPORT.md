# Support

Flowy Docs is a one-person project, so a first answer can take a few days.

- **A question or an idea.** Start a thread in [Discussions](https://github.com/feluminais/flowy-docs/discussions). Check the [Guide](docs/guide.md) first: it says which page answers what.
- **A bug or a feature request.** Open an [issue](https://github.com/feluminais/flowy-docs/issues/new/choose) and fill in the form.
- **A security problem.** Report it privately, see [SECURITY.md](SECURITY.md).
